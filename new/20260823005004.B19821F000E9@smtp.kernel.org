btrfs: zstd: keep the last max level workspace out of reclaim

This commit changes how the last max level zstd workspace is protected
from reclaim, replacing an idle list snapshot check with a dedicated
pinned_ws pointer. This ensures at least one max level workspace is kept
off the LRU list, preventing the reclaim timer from freeing it and
stranding sleeping tasks.
