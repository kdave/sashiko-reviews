btrfs: fix transaction use-after-free in raid stripe insertion

This commit removes a premature btrfs_end_transaction() call in the error
path of btrfs_insert_one_raid_extent(). Removing it prevents a transaction
use-after-free, as the caller still owns the transaction handle and will
clean it up.
