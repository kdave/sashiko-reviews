btrfs: validate root ref item size and name length

ROOT_REF and ROOT_BACKREF items contain a struct btrfs_root_ref followed
by one variable-length name. This commit adds root ref validation to the
tree checker before other Btrfs code consumes them. It rejects items that
are too small, names larger than BTRFS_NAME_LEN, and sizes that do not
match the expected size.
