[Severity: High]
Will this cause an out-of-bounds access when iterating across large folios?

The function kmap_local_folio() maps only a single page from the folio.
When a large folio is used, the inner loop continues advancing cur up to
next_pos, and the pointer arithmetic adds offset_in_folio(folio, cur) to
in_data.

If CONFIG_DEBUG_KMAP_LOCAL_FORCE_MAP is enabled, accessing beyond PAGE_SIZE
from the pointer returned by kmap_local_folio() will cause a page fault or
read from unrelated fixmap slots. Does this mapping need to be re-acquired
for each page within the folio during the iteration?
