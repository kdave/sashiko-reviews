- [Critical] In `verify_one_parity_step()`, the `pages` array is corrupted by `async_gen_syndrome()` on its synchronous fallback path, replacing `struct page *` entries with virtual addresses. This leads to fatal out-of-bounds memory accesses when `kmap_local_page()` is called on them.

- [High] The `async_tx` API's synchronous fallback paths do not support `HIGHMEM` pages, leading to a NULL pointer dereference when BTRFS processes BIO pages mapped in high memory on 32-bit platforms.
- [Medium] Missing `scribble` buffer silently disables DMA offloading for all RAID6 recovery operations.
