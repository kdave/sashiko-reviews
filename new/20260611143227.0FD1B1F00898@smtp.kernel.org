btrfs: fix use-after-free on reloc root after error in insert_dirty_subvol()

If insert_dirty_subvol() fails, the root's reloc_root could be left pointing
to a freed reloc root. This patch resets root->reloc_root if an error
occurs while merging a reloc root to prevent a use-after-free or double free.

Link: https://lore.kernel.org/linux-btrfs/6a1ebde9.c1435f33.112120.0176.GAE@google.com/
