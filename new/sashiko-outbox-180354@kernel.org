Should btrfs_set_data_reloc_bg() also recheck that bg is still empty and
!bg->ro under bg->lock when migrate is false (i.e. when bg->space_info is
already data_sinfo->sub_group[0])?

When no empty block group is found in data_sinfo,
btrfs_zoned_reserve_data_reloc_bg() sets space_info = data_sinfo->sub_group[0],
allocates a chunk with btrfs_chunk_alloc(trans, space_info, alloc_flags,

unused block group onto fs_info->unused_bgs via
