btrfs: test POSIX ACL changes for RO btrfs property

This commit adds a test to verify that POSIX ACLs cannot be modified on a btrfs
subvolume when the read-only property is set to true. It attempts to set and
remove access ACLs, expecting failure while read-only and success once writable.

[Severity: Medium]
Is this patch intended for the xfstests repository rather than the Linux
kernel tree?

This script relies on the xfstests framework functions like _begin_fstest
and _require_acls, which are not present in the kernel source tree. Without
that framework, this test cannot be executed here and will remain orphaned.
Tests intended to live directly in the kernel tree typically belong under
tools/testing/selftests/.
