btrfs: zoned: reset meta_write_pointer on zone reset

This commit updates btrfs_reset_unused_block_groups to reset the
meta_write_pointer for metadata and system block groups when a zone is
reset. This prevents newly allocated tree blocks from ending up behind a
stale write pointer and pinning their folio indefinitely.

This is also a pre-existing issue, but I wanted to ask about the reference

The btrfs_put_block_group(bg) call earlier in this loop drops a reference
