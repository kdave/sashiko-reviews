btrfs: balance: fix potential bg lookup failure in chunk_usage_filter()

Running btrfs balance with a usage filter (-dusage=N) can trigger a KASAN
null-ptr-deref when metadata corruption causes a chunk to have no
corresponding block group. This patch adds a NULL check after
btrfs_lookup_block_group() in chunk_usage_filter() and propagates the error.
