[Severity: High]
Does moving btrfs_free_device(device) above the BTRFS_DEV_STATE_WRITEABLE
check cause a use-after-free on device?

btrfs_free_device() frees both device->name and device before the subsequent
code tests device->dev_state, calls btrfs_scratch_superblocks(fs_info, device)
(which reads device->bdev and device->name), and flushes device->bdev:

fs/btrfs/volumes.c:btrfs_rm_device() {
	...
	if (test_bit(BTRFS_DEV_STATE_WRITEABLE, &device->dev_state)) {
		btrfs_scratch_superblocks(fs_info, device);
		if (device->bdev) {
			sync_blockdev(device->bdev);
			invalidate_bdev(device->bdev);
		}
	}
}

While list_del_rcu(&cur_devices->seed_list) needs to happen under
device_list_mutex, synchronize_rcu(), btrfs_free_device(device), and
free_fs_devices(cur_devices) should remain after the superblock scratching and
block device flushing.
