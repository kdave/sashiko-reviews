btrfs: allow any block size that is no larger than page size
    
This commit relaxes the 4K limitation for block sizes smaller than the page
size. It allows any block size up to PAGE_SIZE for regular builds, and
between BTRFS_MIN_BLOCKSIZE and BTRFS_MAX_BLOCKSIZE for experimental builds.
