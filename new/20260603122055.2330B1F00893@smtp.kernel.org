btrfs: fix inline reflink deadlock at non-zero offset

This commit updates i_size after a successful copy_inline_to_page() in
the early non-zero offset path of clone_copy_inline_extent(). This
matches the existing copy_to_page path and prevents a deadlock where
writeback invalidates a folio beyond EOF and blocks on the extent range
lock.
