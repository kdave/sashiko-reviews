Is it intentional to unconditionally unmount self->b without checking
the self->mounted_b state?

is never evaluated. Unconditionally unmounting self->b relies on umount2() to
safely fail with EINVAL if the device is not mounted, resulting in dead code
and inconsistency with how self->mounted_a is handled.
