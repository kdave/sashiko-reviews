btrfs: also validate compression levels in btrfs_compress_is_valid_type()

This patch changes btrfs_compress_is_valid_type() to use
btrfs_match_compress_type() and btrfs_compress_str2level() for validation.
It also removes the length parameter under the assumption that the input
string is NUL-terminated.

[Severity: High]
Are xattr payloads provided by userspace guaranteed to be NUL-terminated?

When userspace calls setxattr with a property payload that lacks a trailing
NUL byte (e.g., exactly 4 bytes for 'zstd'), the VFS layer passes this raw
buffer down to the filesystem. Internal property inheritance via
iterate_object_props() also reads raw bytes without appending a NUL byte.
