[Severity: High]
Will removing this parameter completely cause mount failures for users who
still have "usebackuproot" configured in their /etc/fstab or kernel command
line?

Without this parameter present in btrfs_fs_parameters, vfs_parse_fs_param()
will treat it as an unrecognized option and return -ENOPARAM, which translates
to a mount failure. 

Could this break backward compatibility and render systems unbootable upon a
kernel upgrade if the filesystem is the root partition?
