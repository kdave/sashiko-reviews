[Severity: Medium]
Can an append-only block group be added to fs_info->reclaim_bgs while it is
still non-full, and then fill up before btrfs_reclaim_block_group() runs?

In fs/btrfs/block-group.c:btrfs_update_block_group(), freeing an extent from
an active, non-full block group (bg->alloc_offset < bg->zone_capacity) queues
it for reclaim as soon as bg->used crosses below thresh_bytes:

fs/btrfs/block-group.c:btrfs_update_block_group() {
	...
		if (READ_ONCE(space_info->periodic_reclaim))
			btrfs_space_info_update_reclaimable(space_info, num_bytes);
		else
			reclaim = should_reclaim_block_group(cache, num_bytes);
	...
	} else if (!alloc && reclaim) {
		btrfs_mark_bg_to_reclaim(cache);
	}
}

Similarly, when space_info->periodic_reclaim is enabled,
fs/btrfs/space-info.c:do_reclaim_sweep() queues non-full block groups whose
bg->used is below the threshold:

fs/btrfs/space-info.c:do_reclaim_sweep() {
	...
		thresh = mult_perc(bg->length, thresh_pct);
		if (bg->used < thresh && bg->reclaim_mark) {
			will_reclaim = true;
			reclaim = true;
		}
		bg->reclaim_mark = true;
		spin_unlock(&bg->lock);
		if (reclaim)
			btrfs_mark_bg_to_reclaim(bg);
}

Because adding a block group to fs_info->reclaim_bgs does not mark it
read-only or prevent further allocations,
fs/btrfs/extent-tree.c:do_allocation_zoned() can continue allocating from it
until bg->alloc_offset reaches bg->zone_capacity:

fs/btrfs/extent-tree.c:do_allocation_zoned() {
	...
	spin_lock(&block_group->lock);
	if (block_group->ro || btrfs_zoned_bg_is_full(block_group)) {
		ret = 1;
	}
}

If the block group fills up to nearly 100% capacity (or 100% capacity if
queued by do_reclaim_sweep()) before btrfs_reclaim_block_group() processes it,
btrfs_zoned_bg_is_full(bg) will now be true.

By skipping should_reclaim_block_group() whenever btrfs_zoned_bg_is_full(bg)
is true at reclaim time, won't btrfs_reclaim_block_group() unconditionally
relocate those newly filled block groups even though their bg->used is well
above the reclaim threshold (or when bg_reclaim_threshold has been set to 0)?
