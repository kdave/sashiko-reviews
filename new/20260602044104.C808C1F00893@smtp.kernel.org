[Severity: High]
Is it expected to call _require_batched_discard before mounting the scratch
filesystem?

Because the filesystem has not yet been mounted at $SCRATCH_MNT, fstrim will
operate on the underlying host filesystem where the empty mountpoint directory
resides.

Could this evaluate the discard capability of the host filesystem instead of
the scratch devices, and potentially unintentionally trim the host filesystem?

Should this check be deferred until after the _mount command?
